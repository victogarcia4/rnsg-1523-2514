Four content types, all built for **visual learners** and backed up to Google Drive by the professor after local creation.

| # | Deliverable | Granularity | Key requirement |

| 1 | **Study Guide (PDF)** | One per session (4 per course) | Color-coded, table/diagram-forward, minimal prose, self-check questions |

---

## 3. Visual-learner design standard

Applies to Study Guides, PPTs, and infographics alike.

- **Palette (LSC):** blue `#003768` = structure/core concept; red `#B30838` = danger/priority action; tan `#F1C585` = "Take Note!" callouts; light blue `#C7EAFB` = support/framework.
- **One concept per visual**; diagrams and tables before prose; short phrases, not paragraphs.
- **Color never carries meaning alone** — always paired with a label, symbol, or written action word.
- **Every infographic** carries alt text + a plain-text companion summary (accessibility + review).
- **Study guides and slides reinforce each other** using the same color codes and table formats.
- **Speaker notes** on every slide use the eight locked fields listed in Section 2.

### CSV columns (secure master — faculty only)

```
Course, Item_Number, Topic, SLO_ID, Item_Type, Match_Set_ID, Bloom_Level,
NGN_CJ_Function, Question_Stem,
Option_A, Option_B, Option_C, Option_D, Option_E, Option_F,
Correct_Letter, Correct_Text, Rationale, Distractor_Rationales,
Source_Textbook, Source_Official, Remediation_Tag
```

- `Correct_Letter` + `Correct_Text` (nominal) are both required.
- `Item_Type` ∈ {MCQ, SATA, Matching}; `Match_Set_ID` groups matching prompts (1 row per scored pair).
- `Bloom_Level` ∈ {Remember, Understand, Apply, Analyze}; `NGN_CJ_Function` ∈ the six NCSBN clinical-judgment functions.
- `Remediation_Tag` ties each item to a concept tag for post-exam remediation.
- A separate student-safe CSV (answers/rationales stripped) is produced for LMS import.

## 7. Backup & storage

- **PPT + PDF:** final native Google Slides and PDFs are saved locally first; the professor uploads to the Google Drive destination and retains the local copy as backup.
- **Infographics:** PNG + alt-text/plain-text companion stored alongside the session they belong to.
- **Exams:** secure master CSV kept faculty-only (not in student-facing folders); only the student-safe CSV is distributed.
