## SLIDE 06 — OVARIAN CYCLE
**Image:** `1523_D1_S06_ovarian.png` — ovarian cycle phases diagram
```
OVARIAN CYCLE (28-DAY)

Follicular Phase (Day 1–14)
→ FSH grows follicle, estrogen rises.

Ovulation (Day 14)
→ LH surge, follicle ruptures, oocyte released.

Luteal Phase (Day 15–28)
→ Corpus luteum secretes progesterone.
→ No fertilization → hormone drop → menses.

Ovulation = 14 days before NEXT menses.
```

ENDOMETRIAL (UTERINE) CYCLE

Proliferative → Estrogen thickens endometrium.

## SLIDE 11 — TAKE NOTE: NSAIDs
**Image:** `1523_D1_S11_nsaids.jpg` — medication/treatment icon
```
■ TAKE NOTE! NSAID STRATEGY

Start NSAIDs BEFORE pain becomes severe.
Begin 1–2 days before expected menses onset.
Continue on SCHEDULED basis (not PRN).
Ibuprofen 400–800 mg q6–8h (max 2,400/day).
Take with food.

No relief in 3–6 months? → Investigate!
```

## SLIDE 12 — MENOPAUSE DEFINITION
**Image:** `1523_D1_S12_menopause.jpg` — aging/life transition
```
MENOPAUSAL TRANSITION

Menopause = 1 year without menses.
Average age: 51.4 years (range 47–55).

Perimenopause = Transition before final period.
Begins ~age 47, lasts 7–14 years.

It is a natural process, NOT a disease.
```

## SLIDE 15 — MENOPAUSE MANAGEMENT
**Image:** `1523_D1_S15_management.jpg` — treatment options
```
MANAGING MENOPAUSAL SYMPTOMS

VMS = MHT gold standard for moderate-severe.
Non-hormonal: SSRIs, gabapentin, fezolinetant.

GSM = Vaginal estrogen, moisturizers, ospemifene.

Osteoporosis = Calcium 1,200 + Vit D 800 IU.
Weight-bearing exercise, DEXA baseline.

MHT safest under age 60 / within 10 years.
```
