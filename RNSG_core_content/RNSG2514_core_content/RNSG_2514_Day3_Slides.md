## SLIDE 04 — DYSTOCIA: THE 5 Ps
**Image:** `2514_D3_S04_dystocia.png`
```
DYSTOCIA — THE 5 Ps

| P | Factor |
|---|---|
| Power | Expulsive forces |
| Passenger | Fetus |
| Passage | Pelvis & canal |
| Position | Maternal position |
| Psyche | Maternal stress |

~50% of unplanned cesareans (nulliparous).
```

## SLIDE 05 — HYPERTONIC vs HYPOTONIC
**Image:** `2514_D3_S05_hypertonic.jpg`
```
HYPERTONIC vs HYPOTONIC

| Feature | Hypertonic | Hypotonic |
|---|---|---|
| Phase | Latent | Active |
| Contractions | Uncoordinated | Weak |
| Pain | Increased | Less |
| Management | Rest + sedation | Amniotomy + oxytocin |
```

## SLIDE 06 — SHOULDER DYSTOCIA
**Image:** `2514_D3_S06_shoulder.png`
```
SHOULDER DYSTOCIA

Head delivers, shoulders wedged behind
pubic bone. Obstetric emergency.

Response: McRoberts maneuver +
suprapubic pressure (NOT fundal).

Avoid: fundal pressure, strong traction.
Assess newborn for Erb palsy, fractures.
```

---

## SLIDE 07 — TAKE NOTE: NO FUNDAL PRESSURE
**Image:** `2514_D3_S07_fundal.jpg`
```
■ TAKE NOTE! SHOULDER DYSTOCIA

FUNDAL pressure is contraindicated.
It does not free the shoulder —
it increases injury risk.

Use SUPRAPUBIC pressure
with McRoberts maneuver.
```

## SLIDE 08 — INDUCTION vs AUGMENTATION
**Image:** `2514_D3_S08_induction.jpg`
```
INDUCTION vs AUGMENTATION

| Term | Definition |
|---|---|
| Induction | Start contractions BEFORE labor |
| Augmentation | Enhance contractions AFTER labor |

Induction requires medical indication.
Augmentation = oxytocin in progress.
```

## SLIDE 09 — BISHOP SCORE
**Image:** `2514_D3_S09_bishop.jpg`
```
BISHOP SCORE — CERVICAL READINESS

Range 0–13.
>8 = favorable (likely succeed).
<5 = unfavorable → ripen first.

Evaluates: dilation, effacement,
station, consistency, position.
```

## SLIDE 10 — OXYTOCIN NURSING
**Image:** `2514_D3_S10_oxytocin.jpg`
```
OXYTOCIN (PITOCIN) NURSING

10 units in 1,000 mL isotonic IV pump.
Titrate to contractions every 2–3 min.

Monitor: contractions, FHR, VS,
I&O, cervical progress.

DISCONTINUE: tetany >90 sec,
tachysystole, Category II/III.
```

---

## SLIDE 11 — TAKE NOTE: RESTING TONE
**Image:** `2514_D3_S11_resting-tone.jpg`
```
■ TAKE NOTE! UTERINE RESTING TONE

Resting tone above 20 mm Hg
compromises uteroplacental perfusion
→ fetal hypoxia.

Continuous FHR monitoring mandatory.

Tachysystole: >5 ctx/10 min over 30 min.
→ Stop/decrease oxytocin.
```

## SLIDE 12 — CORD PROLAPSE
**Image:** `2514_D3_S12_cord-prolapse.png`
```
UMBILICAL CORD PROLAPSE

Cord slips ahead of presenting part.
Obstetric emergency — occlusion = death.

Risk: malpresentation, prematurity,
hydramnios, PROM, unengaged part.

First sign: sudden bradycardia or
variable decels after ROM.
```

---

## SLIDE 13 — CORD PROLAPSE RESPONSE
**Image:** `2514_D3_S13_cord-response.jpg`
```
CORD PROLAPSE — EMERGENCY RESPONSE

1. Call for help — stay with patient.
2. Push presenting part off cord.
3. Position: knee-chest / Trendelenburg.
4. NEVER replace cord into uterus.
5. Oxygen, continuous FHR.
6. Prepare emergency cesarean.

Hand stays in place until delivery.
```

---

## SLIDE 14 — UTERINE RUPTURE (TOLAC)
**Image:** `2514_D3_S14_rupture.jpg`
```
UTERINE RUPTURE — TOLAC

Triad during TOLAC:
→ Sudden tearing pain between contractions
→ Loss of fetal station (part rises)
→ Prolonged bradycardia (FHR 60s–70s)

Rupture until proven otherwise.
```

---

## SLIDE 15 — RUPTURE EMERGENCY ACTIONS
**Image:** `2514_D3_S15_rupture-actions.jpg`
```
RUPTURE — EMERGENCY ACTIONS

1. STOP oxytocin immediately.
2. Call for help — notify surgical team.
3. Prepare emergency cesarean (no imaging).
4. Large-bore IV, prepare blood.
5. Position for perfusion, O2 if hypoxic.

Dual emergency: fetal hypoxia + maternal bleed.
```

## SLIDE 16 — KEY TERMS: LABOR
**Image:** `2514_D3_S16_terms-labor.jpg`
```
KEY TERMINOLOGY — LABOR

Dystocia = abnormal labor progression
CPD = Cephalopelvic disproportion
Tachysystole = >5 ctx/10 min
MVU = Montevideo units (≥200 adequate)
Bishop score = cervical favorability
Labor arrest = replaces "failure to progress"
TOLAC/VBAC = trial of labor after cesarean
```

## SLIDE 30 — QUICK RECALL (2/2)
**Image:** `2514_D3_S30_recall2.jpg`
```
QUICK RECALL — PART 2

Oxytocin: continuous FHR,
d/c if tachysystole or Cat II/III.

Tachysystole: >5 ctx/10 min → reduce oxytocin.

Cord prolapse: push part off cord,
knee-chest/Trendelenburg, hand stays.

Uterine rupture: tearing pain +
loss of station + bradycardia → cesarean.
```
