## SLIDE 05 — TAKE NOTE: CEPHALOHEMATOMA vs CAPUT
**Image:** `2514_D4_S05_cephalohematoma.jpg`
```
■ TAKE NOTE! SCALP SWELLING

Cephalohematoma: subperiosteal,
does NOT cross suture lines,
resolves in weeks.

Caput succedaneum: edema,
crosses suture lines,
resolves in days.

Both resolve on their own.
```

## SLIDE 06 — HYPERBILIRUBINEMIA
**Image:** `2514_D4_S06_jaundice.png`
```
HYPERBILIRUBINEMIA (JAUNDICE)

TSB >5 mg/dL. ~80% of newborns jaundiced.

| Feature | Physiologic | Pathologic |
|---|---|---|
| Onset | After 24 h | Within 24 h |
| Peak | Day 3–4 | Variable |
| Rise | Slow | >5 mg/dL/day |
| Tx | Feedings | Phototherapy |
```

## SLIDE 07 — PHOTOTHERAPY
**Image:** `2514_D4_S07_phototherapy.png`
```
PHOTOTHERAPY

Blue LED converts bilirubin to
water-soluble isomers.

Nursing: expose skin, cover eyes
and genitals, turn every 2 h,
monitor temp, watch dehydration.

Severe TSB ≥25 → kernicterus (BIND).
```

## SLIDE 08 — TAKE NOTE: EARLY JAUNDICE
**Image:** `2514_D4_S08_early-jaundice.jpg`
```
■ TAKE NOTE! JAUNDICE BEFORE 24 HOURS

Jaundice before 24 hours of age =
pathologic until proven otherwise.

Report immediately.
Use TCB or TSB — do NOT rely
on visual estimate.
```

## SLIDE 09 — INFANT OF DIABETIC MOTHER
**Image:** `2514_D4_S09_idm.jpg`
```
INFANT OF A DIABETIC MOTHER (IDM)

Maternal hyperglycemia →
fetal hyperinsulinism →
macrosomia + hypoglycemia.

Problems: hypoglycemia, macrosomia,
RDS, hypocalcemia, polycythemia,
hyperbilirubinemia.
```

---

## SLIDE 10 — IDM PRIORITY ACTIONS
**Image:** `2514_D4_S10_idm-actions.jpg`
```
IDM PRIORITY NURSING

→ Blood glucose hourly ×4h, then q3–4h.
→ <40 mg/dL = hypoglycemia.
→ Early feeding (breast or formula).
→ If unstable: IV dextrose.
→ Neutral thermal environment.
→ Monitor RDS, calcium, bilirubin.
```

## SLIDE 11 — NEONATAL SEPSIS
**Image:** `2514_D4_S11_sepsis.jpg`
```
NEONATAL SEPSIS

Bloodstream infection first 28 days.
Early-onset = vertical. Late = nursery.

Organisms: GBS, E. coli.
Risk: GBS+, ROM >18h, fever,
chorioamnionitis, prematurity.

Signs: "doesn't look right" —
temp instability, poor feeding.
```

## SLIDE 15 — FHR CATEGORIES
**Image:** `2514_D4_S15_fhr.jpg`
```
FHR CATEGORY → ACTION

Category I = normal → routine.
Category II = indeterminate → resuscitate.
Category III = abnormal → expedite delivery.

Intrauterine resuscitation:
reposition, IV fluids, reduce uterotonics.
```

---

## SLIDE 16 — TAKE NOTE: NO ROUTINE O2
**Image:** `2514_D4_S16_no-o2.jpg`
```
■ TAKE NOTE! ROUTINE O2 REVERSAL

Routine maternal oxygen NOT recommended
for Category II/III when SpO2 normal
(ACOG 2025 reversal).

Give O2 only if maternal hypoxia present.

Intrauterine resuscitation FIRST.
```

## SLIDE 17 — NRP / ABC
**Image:** `2514_D4_S17_nrp.png`
```
NEWBORN RESUSCITATION (NRP / ABC)

1. Dry, stimulate, warm.
2. Airway: position, suction.
3. Breathing: PPV (most important).
4. Circulation: compressions if HR <60.

Goal: HR >100, spontaneous breathing,
pink tongue.
```

---

## SLIDE 18 — FETAL DEMISE
**Image:** `2514_D4_S18_demise.jpg`
```
FETAL DEMISE & PERINATAL LOSS

Miscarriage: before 20 weeks.
Stillbirth/IUFD: after 20 weeks.
Neonatal death: first 28 days.

Confirm: absent cardiac activity.

Nursing: compassion, honor wishes,
memory-making, monitor coagulopathy.
```

---

## SLIDE 19 — TAKE NOTE: GRIEF SUPPORT
**Image:** `2514_D4_S19_grief.jpg`
```
■ TAKE NOTE! BEREAVEMENT CARE

Allow viewing, holding, keepsakes.
Use the word "died."
Honor cultural practices.
Include the partner.

Never say "you can have another."
Monitor maternal safety (DIC risk).

Grief has no timeline.
```

## SLIDE 34 — QUICK RECALL (1/2)
**Image:** `2514_D4_S34_recall1.jpg`
```
QUICK RECALL — PART 1

Cephalohematoma: does NOT cross sutures.
Caput: crosses sutures, resolves fast.
Erb palsy: upper plexus, grasp present.

Physiologic jaundice: after 24h, Day 3–4.
Pathologic: before 24h, rapid rise.
BIND/kernicterus: TSB ≥25.

IDM hypoglycemia: <40, feed or dextrose.
```

## SLIDE 35 — QUICK RECALL (2/2)
**Image:** `2514_D4_S35_recall2.jpg`
```
QUICK RECALL — PART 2

TTN: retained fluid, cesarean.
RDS: surfactant deficiency, ground-glass.
MAS: meconium, ball-valve.
Sepsis: GBS/E. coli, start antibiotics.

VEAL CHOP: Late = placental insufficiency.
Category II → resuscitate; III → deliver.
NRP: PPV = most important step.

Perinatal loss: allow holding, never blame.
```
